# 1. Core Goal

A system where a **Supervisor Agent** receives a research query (e.g., _"Summarize latest AI alignment research"_), delegates it to specialized worker agents, and returns an aggregated, high-quality report.

---

# 2. High-Level Agent Roles

| Agent Type        | Responsibilities                                                              | Communication                                      |
|-------------------|-------------------------------------------------------------------------------|----------------------------------------------------|
| **Supervisor Agent** | Task breakdown, worker assignment, progress monitoring, final aggregation.   | Direct to workers (A2A) & orchestrates.            |
| **Search Agent**     | Queries search engines, academic APIs (Google Scholar, PubMed, Arxiv).       | Sends search results to Data Agent.                |
| **Data Agent**       | Cleans, deduplicates, and structures raw documents.                         | Sends cleaned data to NLP Agent.                   |
| **NLP Agent**        | Summarizes, extracts key points, identifies trends.                         | Sends summaries to Fact-Check Agent.               |
| **Fact-Check Agent** | Validates claims against authoritative sources.                             | Sends verified findings to Report Agent.           |
| **Report Agent**     | Formats final output (Markdown, PDF, HTML).                                 | Sends back to Supervisor for delivery.             |

---

# 3. Workflow

**Step 1 – User Request**  
User sends query → Supervisor Agent.

**Step 2 – Task Breakdown**  
Supervisor splits into subtasks:
1. Search relevant sources
2. Clean and filter data
3. Summarize
4. Fact-check
5. Compile report

**Step 3 – Parallel Worker Execution**  
Search Agent, Data Agent, and NLP Agent work in parallel using A2A messaging to exchange partial results without waiting for Supervisor in between.

**Step 4 – Iterative Refinement**  
Supervisor reviews summaries → asks NLP Agent for deeper analysis if needed.

**Step 5 – Output Delivery**  
Final structured report generated by Report Agent and sent to the user.

---

# 4. Communication Model

Use **Google A2A-style RPC messaging** between agents:

**Message Format:** JSON schema with sender, receiver, task_id, payload.

**Transport Options:**
- **Local Dev** → Python asyncio or LangGraph state passing.
- **Distributed** → gRPC or WebSocket channels.

**Example Message:**
```json
{
  "sender": "SearchAgent",
  "receiver": "DataAgent",
  "task_id": "research_001",
  "payload": {
    "papers": [
      {"title": "AI Alignment Methods", "url": "https://arxiv.org/..."}
    ]
  }
}
```

## 5. Tech Stack
Agent Frameworks: LangGraph, Haystack, or custom Python + FastAPI

Search APIs: Arxiv API, PubMed API, Google Scholar scraping (SerpAPI)

LLM Models: GPT-4 / Claude for summarization, BAAI/bge for reranking

Fact-Checking: CrossRef, Wikipedia API, knowledge graphs

Storage: MongoDB / Elasticsearch for caching sources

Deployment: Docker containers per agent, orchestrated with Kubernetes

## 7. Implementation Phases
MVP – All agents as Python classes in a single process (LangGraph or asyncio).

Networked – Separate microservices for each agent using WebSocket RPC.

Scalable – Deploy each agent in its own container, auto-scale workers based on load.

Advanced – Add learning memory so agents get better at searching/summarizing over time.
